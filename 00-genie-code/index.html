0) Genie Code 시작하기¶

  • 약 20분
  • 페이지 4개
  • 기본

Genie Code는 노트북·SQL Editor·Catalog·Job·MLflow 화면 옆에서 쓰는 AI 작업 동료입니다. 코드를 설명하고, 셀을 만들고 실행하고, 오류를 고칩니다. 오늘 실습에서는 처음부터 끝까지 Genie Code를 옆에 열어 두고 씁니다.

기본 상태의 Genie Code는 이 실습의 공유 데이터 위치, 모델 이름 규칙, 별칭 의미, 패키지 규칙을 모릅니다. 실습 전에 이 규칙을 한 번 적어 두면 프롬프트마다 같은 설명을 반복하지 않아도 됩니다.

워크스페이스 전체 설정은 바꾸지 않습니다

이 워크스페이스는 ML 실습 말고도 여러 업무에 쓰입니다. 그래서 모든 사용자에게 적용되는 워크스페이스 인스트럭션·워크스페이스 스킬은 쓰지 않고, 실습 폴더와 나에게만 적용되는 설정만 씁니다.

0.1 · 실습 폴더AGENTS.md이 폴더 안에서만 읽히는 규칙

0.2 · 나내 스킬 설치노트북 1개 실행

0.3 · 나내 인스트럭션내 스키마 · 선호

0.4 · 나첫 대화공유 데이터 살펴보기

커스터마이징 방법¶

방법 위치 누가 적용 범위 오늘
폴더 규칙 AGENTS.md mlops_workshop/AGENTS.md 실습 패키지에 포함 이 폴더(와 하위) 노트북·파일을 열었을 때 ✅ 데이터 위치, 모델·별칭 규칙, 패키지 규칙 → 0.1
사용자 스킬 /Users/<나>/.assistant/skills/<이름>/SKILL.md 각 실습자 나에게만, 요청이 스킬 설명과 맞을 때 또는 @스킬이름 ✅ phm-mlflow-uc, phm-training-job → 0.2
사용자 인스트럭션 /Users/<나>/.assistant_instructions.md 각 실습자 나의 모든 응답 ✅ 내 스키마, 선호 → 0.3
워크스페이스 인스트럭션 /Workspace/.assistant_workspace_instructions.md 워크스페이스 관리자 모든 사용자의 모든 응답 ❌ 오늘은 쓰지 않음
워크스페이스 스킬 /Workspace/.assistant/skills/ 관리자 모든 사용자 ❌ 오늘은 쓰지 않음
  • Genie Code는 노트북·파일을 열면 그 폴더부터 상위 폴더로 올라가며 AGENTS.md·CLAUDE.md를 찾아 읽습니다. 따로 설정할 것이 없습니다.
  • 인스트럭션 파일은 20,000자까지만 읽습니다. 길고 자세한 절차는 스킬로 옮깁니다.
  • 인스트럭션은 Quick Fix와 자동완성에는 적용되지 않습니다.

운영에서는

ML팀 전용 워크스페이스라면 같은 규칙을 워크스페이스 인스트럭션·스킬로 올려 팀 표준으로 쓸 수 있습니다. 여러 팀이 함께 쓰는 워크스페이스라면 오늘처럼 팀 Git 폴더의 AGENTS.md 와 사용자 스킬로 범위를 좁힙니다.

이 실습에 왜 필요한가¶

실습에서 부딪히는 문제 적어 두는 곳
공유 데이터 phm_shared에 실수로 쓰면 모두의 실습이 망가짐 AGENTS.md (읽기 전용 명시)
필요 없는 %pip install을 넣음 AGENTS.md (환경 버전 5에 이미 있음, 설치 전에 확인)
피처를 노트북마다 다시 짜면 학습·엣지 피처가 달라짐 AGENTS.md (phm_features.py만 사용)
Stage(Staging/Production)로 답하는 옛 예제 스킬 phm-mlflow-uc (별칭 규칙)
"승격이 안 돼요"를 오류로 착각 스킬 phm-training-job (검증이 막는 것이 정상)
같은 워크스페이스에서 여러 명이 실습 내 인스트럭션 (내 스키마만 쓰기)

Genie Code 사용법 요약¶

하고 싶은 일 방법
질문·작업 맡기기 패널에 자연어로 입력. 기본은 에이전트로 동작해 셀을 만들고 실행합니다. 설명만 원하면 "코드는 실행하지 말고 설명만 해줘"라고 씁니다
실행 승인 실행 전 Allow / Skip을 묻습니다. 패널 설정에서 Ask first / Auto-approve를 고릅니다
코드 설명 셀에서 /explain
오류 고치기 오류 셀의 Diagnose error 또는 /fix. 한 줄로 고칠 수 있는 오류는 Quick Fix
환경 오류 /repairEnvironment
문서화 /doc (주석·설명 추가)
스킬 직접 지정 @phm-mlflow-uc처럼 @ 뒤에 스킬 이름
기억시키기 "앞으로 AUC는 소수 셋째 자리까지 보여줘. 기억해" → 메모리에 저장

데이터와 권한

  • Genie Code는 내 Unity Catalog 권한 안에서만 데이터를 읽고 작업합니다. 내가 못 보는 테이블은 Genie Code도 못 봅니다.
  • 파트너 모델 제공자는 이 기능으로 보낸 데이터를 보관하지 않습니다(zero data retention). Databricks는 이 데이터를 제3자용 기반 모델 학습에 쓰지 않습니다.
  • Auto-approve는 편의 기능이지 보안 경계가 아닙니다. 오늘은 실행 전 내용을 읽고 Allow를 누르는 습관을 들입니다.
  • Genie Code의 에이전트 기능은 계정·워크스페이스의 Partner-powered AI features가 켜져 있어야 동작합니다(관리자 설정).
