0.3) 내 인스트럭션¶

기본 내 Genie Code에게 내 스키마 이름과 선호를 알려 줍니다. 0.2)의 설치 노트북이 이미 만들어 두었으니, 내용만 확인합니다. 사용자 인스트럭션은 나에게만 적용됩니다.

1단계 - 내용 확인하기¶

  1. Genie Code 패널 ⋮ → Customizations → Instructions 탭을 엽니다.

  2. User instructions 아래 .assistant_instructions.md에 아래 내용이 들어 있고, <내 스키마>·<내 이메일> 자리에 내 값이 들어갔는지 봅니다. 오른쪽 Edit로 이 화면에서 바로 고칠 수 있습니다.

    .assistant_instructions.md (실습 구역)
    # MLOps 핸즈온 실습 구역 (2026-11-17)

- 이 구역은 `mlops_workshop/` 폴더의 실습 작업에만 적용한다. 다른 업무에는 쓰지 않는다. 실습이 끝나면 지워도 된다.

## 나는 누구인가
- HL만도 ML팀 실습자다. 오늘 실습에서 설비 고장 예측 모델을 학습·등록하고, 학습 파이프라인 Job·배포·감시·재학습까지 한 바퀴 돌린다.

## 내 작업 공간
- 내 스키마: `mlops_edu_dev.<내 스키마>` (예: `mlops_edu_dev.juyeon`)
- 테이블·모델을 만들 때 카탈로그·스키마를 생략하지 말고 항상 `mlops_edu_dev.<내 스키마>.<이름>` 전체 이름을 쓴다.
- 내 모델: `mlops_edu_dev.<내 스키마>.phm_failure_model`
- 내 실험: `/Users/<내 이메일>/phm_failure_<내 스키마>`
- 내 학습 파이프라인 Job: `phm_training_pipeline_<내 스키마>`

## 선호
- 설명은 짧게, 표로 정리한다.
- 지표는 소수 셋째 자리까지 보여 준다(예: AUC 0.940).
- 결과를 보여 줄 때는 행 수나 건수 같은 검증 값을 함께 보여 준다.

노트북 없이 직접 만들려면

User instructions 아래 Add instructions file을 클릭하면 내 홈 폴더에 .assistant_instructions.md가 만들어집니다. 위 내용을 붙여넣고 <내 스키마>·<내 이메일>을 모두 바꿉니다.

2단계 - 확인하기¶

  1. Genie Code 패널에서 새 채팅(+)을 엽니다. 노트북은 mlops_workshop 폴더 안의 것을 열어 둡니다(AGENTS.md가 읽히도록).

  2. 아래 프롬프트를 보내고, 내 스키마·모델·Job 이름과 공유 데이터 위치를 정확히 답하는지 확인합니다.

    프롬프트

    내 실습 스키마, 모델 이름, 학습 파이프라인 Job 이름이 뭐야? 공유 데이터는 어디 있고, 이 실습에서 쓸 수 있는 스킬도 알려줘.

Genie Code 메모리

작업 중에 "앞으로 AUC는 소수 셋째 자리까지 보여줘. 기억해"처럼 말하면 Genie Code가 메모리에 저장해 다음 채팅에서도 기억합니다. 메모리는 인스트럭션 파일과 따로 관리됩니다. 오래 유지할 규칙은 인스트럭션 파일에 적습니다.
