3.2) (Optional) deployment job¶

MLflow 3의 deployment job은 Unity Catalog 모델에 새 버전이 등록될 때마다 자동으로 실행되는 Job입니다. 보통 평가 → 승인 → 배포 태스크로 구성하며, 진행 상황이 모델 버전 화면에 표시됩니다.

상태

  • deployment job 기능은 Public Preview입니다(2026-11 문서 기준).
  • 승인(Approve) 버튼 방식은 experimental입니다.

Step 3 파이프라인과의 차이¶

Step 3 파이프라인 deployment job
시작 스케줄·수동·데이터 도착 새 모델 버전 등록 시 자동
역할 학습부터 승격까지 한 Job 등록된 버전의 평가·승인·배포
승인 직접 태스크 추가 모델 버전 화면의 Approve 버튼 (UC 태그 사용)

연결 방법 (요약)¶

  1. 평가·승인·배포 노트북으로 Job을 만듭니다. Job 파라미터 model_name, model_version이 필요하고, 승인 태스크 이름은 approval로 시작해야 합니다.
  2. 모델 화면 Overview → Deployment job → Connect deployment job에서 그 Job을 고릅니다. 코드로는 MlflowClient().update_registered_model(name, deployment_job_id=...)를 씁니다.
  3. 이후 새 버전이 등록되면 자동 실행됩니다. 승인 태스크에서 멈추면 승인자가 Approve를 누르고, 그러면 Job이 이어서 실행됩니다.

권한

  • deployment job은 모델 소유자의 권한으로 자동 실행됩니다.
  • 그래서 실행 주체(Run as)는 최소 권한의 서비스 주체로 두는 것을 권장합니다.
  • 승인자는 governed tag 정책으로 제한할 수 있습니다.
