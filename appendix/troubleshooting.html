부록: 문제 해결¶

증상 원인 해결
위젯 '내 스키마'에 ... 입력하세요 위젯이 비어 있음 노트북 위쪽 위젯에 영문 이름 입력
No module named 'phm_features' 폴더 구조가 바뀜 mlops_workshop/step1~step5 구조 그대로 두기. .py 모듈이 노트북으로 바뀌었다면 다시 가져오기
No module named 'mlflow' 서버리스 환경 버전이 5보다 낮음 Environment 패널에서 환경 버전 5 선택 후 Apply
TABLE_OR_VIEW_NOT_FOUND ... phm_features Step 1을 건너뜀 Step 1 노트북 먼저 실행
RESOURCE_DOES_NOT_EXIST ... @champion Step 2를 건너뜀 Step 2 노트북 먼저 실행
Step 3 실행 결과 not promoted 정상 동작 (champion보다 나아지지 않음) Step 5에서 새 데이터로 재학습하면 승격
엣지 앱 목록에 내 스키마가 없음 모델이 없거나 앱 권한 없음 Step 2 완료 확인, 진행자에게 앱 권한 확인 요청
엔드포인트 호출 403 엔드포인트 권한 없음 진행자(또는 워크스페이스 관리자)에게 Can query 권한 요청
앞 Step을 못 끝냄 시간 부족 해당 Step 노트북을 Run all 하면 그 Step이 끝까지 완성됩니다. 다음 Step은 바로 이어서 할 수 있습니다
Genie Code 패널이 안 열림 / 에이전트 기능 없음 파트너 AI 기능이 꺼져 있음 워크스페이스 관리자에게 Partner-powered AI features 확인 요청
Genie Code가 실습 규칙을 모름 mlops_workshop 밖의 노트북을 열었거나, 예전 채팅 실습 폴더 안 노트북을 열고 새 채팅. AGENTS.md가 폴더에 있는지 확인(0.1)
스킬이 목록에 없음 설치 노트북을 실행하지 않았거나, 설치 뒤 새 채팅을 안 엶 step0/0_setup_my_genie_code 실행 후 새 채팅·브라우저 새로 고침
Genie Code가 %pip install을 하려 함 AGENTS.md가 적용되지 않음 Skip을 누르고 "설치하지 말고 환경 버전 5에 있는 라이브러리로 해줘"라고 다시 요청
대시보드 위젯이 비어 있음 Step 4·5 결과 테이블이 없음 phm_predictions(Step 4)·model_monitoring(Step 5)를 먼저 만든 뒤 6_create_dashboard 다시 실행
Genie Agent에서 웨어하우스를 고를 수 없음 웨어하우스 Can use 권한 없음 진행자(또는 워크스페이스 관리자)에게 권한 요청
